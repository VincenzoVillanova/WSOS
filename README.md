# Descrizione
La repository "**WSOS 2024-2025**" è dedicata al corso universitario di WEB AND SERVICE ORIENTED SYSTEMS AND LABORATORY tenuto nell'anno accademico 2024-2025 dai professori **Giuseppe Pappalardo** e **Salvatore Nicotra**. Questo corso è progettato per fornire agli studenti una solida base teorica e pratica sui sistemi concorrenti e distribuiti, con particolare attenzione alle reti di calcolatori. Durante il corso, verranno approfondite le principali tecnologie e protocolli di rete, l'architettura delle reti, e gli aspetti legati alla sicurezza.

## Argomenti trattati

- **Introduzione ai sistemi concorrenti e distribuiti**  
- **Programmazione con socket**:  
  - Principali system call  
  - Gestione di indirizzi IP e socket  
  - DNS e interfaccia al resolver  
- **Comunicazione connectionless e socket non bloccanti**, sia in linguaggio C che in Java  
- **Sviluppo di applicazioni web**:  
  - Java Servlets e principi di Web Application  
  - Servizi web REST con JSON  
- **Sviluppo di applicazioni**:  
  - PHP  
  - Laravel MVC  
  - Spring Boot  
- **Creazione di client per il web e API web**

## Obiettivi

Questo approccio mira a offrire competenze pratiche per progettare e sviluppare applicazioni distribuite e servizi web moderni, fornendo strumenti fondamentali per affrontare le sfide del settore IT.
